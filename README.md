# ATTACK ON TITAN: BEYOND THE WALLS // 進撃の巨人
*“Humanity's future lies beyond the walls.”*

A dark, cinematic anime web application prototype built strictly using **HTML5 and CSS3 only (Zero JavaScript, Zero External Frameworks)**.

---

## 🌟 Key Features
- **Pure CSS Dynamic Blade Cursors**: Ultrahard steel snap-off blade, Levi dual vortex, crystal hardened blade, and Thunder Spear cursors.
- **Titan Nape Precision Slicing Simulator**: Interactive anatomical Titan nape target with directional blade strikes, muscle lacerations, steam vapors, and click-to-sever reactions.
- **Combat Arena (`#battle`)**: 4 multi-move combat keyframe animations (*Dual Blade Strike*, *Levi Spiral Whirlwind*, *Thunder Spear Rocket*, *Attack Titan Hardened Fist*).
- **Anime Character Creator (`#creator`)**: Build your own Scout recruit with live reactive SVG avatar, military branch cloaks, hairstyles, stat gauges, and enlistment stamp.
- **Official Character Photos**: High-resolution anime portraits for Eren, Mikasa, Armin, Levi, Hange, Elena, and Commander Erwin.
- **Military Archives (`#intel`) & Signal Flares (`#mission`)**: Interactive flare protocols and declassified schematics for ODM gear, blades, and walls.

---

## 🚀 How to Run Locally
Simply open `index.html` in any modern web browser, or serve via:
```bash
python -m http.server 8080
```
Then navigate to `http://localhost:8080/`.

---

## 🌐 How to Deploy to GitHub Pages
1. Create a new empty repository on [github.com/new](https://github.com/new) named `anime`.
2. Double-click `push_to_github.bat` and paste your repository URL.
3. On GitHub, go to **Settings** -> **Pages** -> Select `main` branch -> **Save**.
